WK87 probe

Read-only diagnostics. This page never sends a write command (0x07).

What it does: reads lighting values (0x08) from channels 0-5, reads HID feature reports, and listens for unsolicited reports. It never sends a write command. Two questions: does the side panel live on its own lighting channel, and does the firmware report battery anywhere. Run it once on the cable and once on the 2.4G receiver. 
Not connected. Press Connect and pick the device named "87C" or "87C 2.4G dongle".
